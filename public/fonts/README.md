# DejaVu Sans

Fuente libre distribuida localmente para el PDF de lectura limpia. La exportación usa una sola
fuente Regular a 12 pt y comprueba cobertura antes de escribir; no sustituye caracteres ausentes.

Origen del archivo, obtenido el 2026-09-27:

- https://raw.githubusercontent.com/matplotlib/matplotlib/main/lib/matplotlib/mpl-data/fonts/ttf/DejaVuSans.ttf
- https://raw.githubusercontent.com/matplotlib/matplotlib/main/lib/matplotlib/mpl-data/fonts/ttf/LICENSE_DEJAVU

La licencia original está incluida en `LICENSE-DejaVu.txt`. El archivo TTF no fue modificado.
